# Llamingo Films

Sitio web oficial de Llamingo Films, agencia creativa y productora audiovisual en Ecuador.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

El sitio queda disponible en `http://localhost:3000`.

## Comandos

- `pnpm dev`: inicia el entorno de desarrollo.
- `pnpm build`: genera la compilacion de produccion.
- `pnpm lint`: revisa la calidad del codigo.

## Tecnologia

React 19, Next.js 16, Vinext, Vite y TypeScript.
